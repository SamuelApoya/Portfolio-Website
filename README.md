# Portfolio Website

## Samuel Apoya’s Personal Website

## Overview
This repository contains the source code for my personal website. The site serves as a professional portfolio and blog, showcasing my skills, projects, and thoughts on various topics.

## Features
- Homepage with a brief introduction  
- About section with detailed professional information and education  
- Career interests section highlighting areas of expertise  
- Portfolio section showcasing key projects  
- Contact form for professional inquiries  

## Technologies Used
- HTML  
- Cascading Style Sheets (CSS)  
- JavaScript  

## Setup
To run this project locally:

1. Clone the repository  
2. Navigate to the project directory  
3. Open the `index.html` file in your browser
